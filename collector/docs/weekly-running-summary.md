# 주간 러닝 요약

## 화면과 API

- `/today`: 이번 주로 시작하는 주간 합계와 요일별 러닝 횟수. 지난주로 전환 가능.
- `/garmin-connect`: 지난주로 시작하는 합계와 활동 목록. 이번 주로 전환 가능.
- `GET /api/garmin/weekly-summary?week=current|previous`: 관리자 Bearer 토큰 필수.

`TRAINI_TIMEZONE` 서버 설정을 사용하며 기본은 `America/Los_Angeles`입니다. 클라이언트가
전달한 사용자 ID·시간대는 사용하지 않습니다. 관리자 인증 후 확인한 사용자 ID로만 조회하며
기존 활동 RLS는 유지합니다. 서비스 역할 키는 서버 안에서만 사용합니다.

API는 `Cache-Control: private, no-store`와 `Vary: Authorization`을 반환합니다.
인증 실패는 401/403, 잘못된 주간 선택은 400, DB·시간대 설정·집계 실패는 503입니다.
실패 응답에는 DB 진단·키·경로를 포함하지 않습니다. 조회 실패를 성공한 빈 주간으로 바꾸지 않습니다.

## 포함할 기록과 시간대

`activities`에서 본인 소유, `source=garmin_fit`, `activity_type=running` 조건으로 필요한
요약 컬럼만 읽습니다. 원본 JSON·해시·프로필·장치 정보·GPS는 브라우저로 전달하지 않습니다.

DB 조회에는 대상 월~일에 앞뒤 2일을 더한 작은 UTC 범위를 사용하고, 각 활동의 `started_at`을
설정한 시간대로 변환해 **정확한 월요일~일요일 시작일**로 다시 필터링합니다. 일요일 시작해
월요일에 끝난 운동은 일요일에 속합니다. 주간을 고정 168시간으로 계산하거나 서버/브라우저의
현지 시간대에 의존하지 않습니다. DST·연말·윤년을 실제 달력으로 처리합니다.

과거 저장 시점의 `training_timezone`이 현재 설정과 달라도 원래 UTC 시작 시각으로 현재
설정에 맞게 분류합니다. 타임존 설정을 잘못 입력하면 조용히 다른 시간대로 바꾸지 않고 오류를 반환합니다.

500개씩 페이지를 요청하되 서버의 행 제한이 더 작아도 실제 반환 개수와 정확한 전체 개수로
다음 페이지를 읽습니다. 일부 페이지만 합산하지 않습니다. 조회 중 행 개수가 달라지거나
중복·누락이 발견되면 재조회하도록 오류를 반환합니다. 최대 10,000개, 전체 DB 조회 제한은 15초입니다.

## 집계 계약

| 지표 | 계산 |
| --- | --- |
| 러닝 횟수 | 해당 주에 포함된 활동 수 |
| 총 거리 | 거리 값이 있는 활동의 m 합계. 화면에서는 km로 표시 |
| 타이머 시간 | `duration_seconds` 합계. 경과 시간·이동 시간으로 대체하지 않음 |
| 평균 페이스 | 같은 활동에 양수 거리와 타이머 시간이 모두 있는 기록의 시간 합계 ÷ 거리 합계 × 1000 |
| 요일별 횟수 | 훈련 시간대로 변환한 시작일별 횟수 |

짧은 러닝과 긴 러닝의 페이스를 단순 평균하지 않습니다. 거리만 있는 활동과 시간만 있는
다른 활동을 서로 짝지어 계산하지 않습니다. FIT 속도에서 유도한 개별 페이스는 목록에 보여줄
수 있지만 거리/타이머가 없으면 주간 평균 계산에는 넣지 않습니다.

각 지표에 사용한 활동 수를 `coverage`로 반환합니다. 부분 합계면 사용한 기록 수를 안내하고,
활동은 있지만 값이 모두 없으면 `null`/`—`로 표시합니다. 활동이 없는 주는 거리·횟수·시간이 0,
평균 페이스는 null입니다. 음수·무한대·잘못된 숫자는 정상 수치로 변환하지 않고 실패 처리합니다.

계산 결과는 최대 소수점 6자리까지 유지합니다. 화면 거리는 km 소수점 최대 2자리,
평균 페이스는 가장 가까운 초로 반올림합니다. 총 시간은 짧은 기록에는 분·초, 1시간 이상에는
시간·분으로 간략히 표시합니다. 표시값으로 다시 집계하지 않습니다.

## UI 동작과 범위

주간 변경 시 이전 요청을 취소해 이전 주의 결과가 나중에 덮어쓰지 못하게 합니다.
로딩·오류·빈 상태를 구분하고 실패 시 다시 확인할 수 있습니다. 새로고침과 창 포커스 복귀 시
최신 DB 기록을 조회하며, 열린 상태에서 훈련 날짜가 바뀌면 주간과 오늘 표시도 갱신합니다.

주간 목표 40km나 달성률 55% 같은 예시 값을 제거했습니다. 계획이 생성되기 전에는 실제 목표로
오해할 수 있는 진행률을 표시하지 않습니다. 다른 일정·회복·훈련 계획 프로토타입은 이번 범위 밖입니다.
지난주 가져오기 버튼은 수집·분석·업로드를 이어서 실행하고, 저장 단계에 진입한 실행이 끝나면
성공·일부 실패·중단 여부와 관계없이 요약을 다시 조회합니다. 선택한 주간은 유지합니다.

기존 430px 프레임과 색·타이포그래피를 사용합니다. 새 스타일은 CSS 모듈에 한정합니다.
작은 화면에서 지표를 두 열로 정렬하고 긴 텍스트·날짜는 줄바꿈하며, 페이지 전체를 축소하지 않습니다.
폭 320/375/390/430px와 데스크톱 768px(프레임 430px)을 실제 브라우저에서 확인했습니다.
