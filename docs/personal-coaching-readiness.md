# 개인 코칭 사용 준비 검증

마지막 검증은 실제 Garmin 가져오기와 관리자 화면 조회, 격리 계정의 생성·저장 검사를 함께 수행합니다. 개인 계획을 보존하면서 새 기록이 리뷰와 처방 입력에 전달되는지 확인할 수 있습니다.

## 다시 실행하기

로컬 서비스가 3017 포트에서 실행 중이고 기존 관리자·Garmin 연결 설정이 준비돼 있어야 합니다.

```sh
npm run test:readiness
npm run test:readiness -- --import --browser
```

기본 실행은 저장된 기록·리뷰·계획을 조회합니다. `--import`는 지난주와 이번 주의 실제 수집·분석·업로드를 각각 두 번 수행해 반복 실행의 중복 여부까지 확인합니다. `--browser`는 별도 관리자 세션으로 오늘·일정 화면을 열고 320·375·430·768px에서 프레임과 가로 넘침을 검사합니다. 테스트 세션은 종료 시 정리됩니다.

실행 결과의 `planState: stale`과 `explicit_plan_or_review_action_required`는 현재 입력으로 계획·리뷰를 명시적으로 다시 확인해야 한다는 뜻입니다. 이 경우 저장 계획을 최신 처방으로 승인했다고 간주하지 마세요. 기존 계획의 남은 거리와 새 한도가 다를 수 있으며, 새로 가져온 실제 러닝이 원래 처방보다 길었던 경우에도 발생합니다. 검사 명령은 AI 생성 요청을 보내지 않습니다.

조회 과정에서는 서비스의 기존 Garmin 매칭 처리가 실행될 수 있습니다. 계획의 제목·종류·거리·페이스·구성·수동 완료·피드백은 실행 전후 비교하며, 생성 요청이 추가되지 않았는지도 확인합니다.

## 확인한 범위

2026-11-05 검증에서 다음을 확인했습니다. 개인 활동의 날짜·거리·계정 ID·모델 응답은 이 문서에 저장하지 않습니다.

- 실제 지난주·이번 주 수집, FIT 분석, 업로드 및 반복 실행이 성공했습니다. 반복 실행에서 새 삽입과 갱신은 발생하지 않았습니다.
- 지난주 주간 리뷰의 활동 수와 거리·시간은 가져온 기록과 일치했습니다. 저장된 리뷰의 최신 여부와 ChatGPT 연결 상태를 확인했습니다.
- 최신 기록이 훈련 입력과 수행 변화 분석에 전달됐습니다. 개인 저장 계획은 새 기록에 따라 재검토 상태가 됐으며, 기존 처방과 피드백 보존 검사가 통과했습니다.
- 실제 서버의 오늘·일정 탭에서 저장된 계획·리뷰와 주간 거리 표시를 확인했습니다. 모바일 폭 검사와 격리 브라우저 테스트가 통과했습니다. 프로덕션 서버를 재시작한 뒤 같은 API·화면 검사를 다시 통과했습니다.
- 임시 계정의 실제 DB 통합 검사에서 리뷰·계획 생성 서비스에 고정 모델 응답을 공급해 검증, 원자적 저장, 재사용, 조건 변경과 회복 제한을 확인했습니다.
- 익명·위조·비관리자 접근 거부, 관리자 조회, 만료된 토큰 갱신, 로그아웃, CSRF 차단을 확인했습니다.
- 일요일과 평일 처리, 날짜 전환과 DST, 실패 시 기존 데이터 보존, 사용량 한도, 만료된 실행 잠금과 동시 요청 거부를 검증했습니다.
- 처방 통합 검사에 빠져 있던 실제 러닝 요약 모듈 연결을 수정했습니다.

Node 검사 402개, Python 검사 125개, 격리 브라우저 검사 31개와 lint·프로덕션 빌드가 통과했습니다.

실제 OpenAI 호출은 0회였습니다. 이번 검사에서 새 개인 계획의 실제 모델 출력 품질을 평가하지 않았습니다. 개인 일정 재생성은 오늘 탭에서 현재 상태와 주간 기록을 확인한 뒤 별도로 실행합니다. Google 제공자의 로그인·동의 화면을 직접 거치는 과정은 이번 자동 인증 검사 범위 밖입니다.

## 의존성 검사

높은 등급으로 보고되던 개발 도구의 Zod를 호환 범위 안에서 갱신했습니다. 갱신 후 production 의존성 감사 결과는 0건입니다. ESLint 계열의 minimatch 경로에 연결된 중간 등급 8건은 남아 있습니다. 현재 선언된 의존성 범위 안의 갱신으로 해결되지 않아, 상위 도구의 호환 업데이트를 확인하는 후속 유지보수 항목으로 남깁니다.

## 매주 사용하는 순서

1. 워치를 Garmin Connect에 동기화합니다.
2. 오늘 탭에서 안내하는 주의 기록을 가져옵니다. 주중에 생성한다면 이번 주에 이미 달린 기록도 가져옵니다.
3. 한 주의 체감 강도·메모와 현재 컨디션을 확인하고 주간 리뷰를 확인하거나 생성합니다.
4. 일요일에는 다음 주 계획을, 주중에는 이번 주 남은 계획을 생성합니다. 새 기록이나 상태로 기존 계획이 달라져야 할 때는 이번 주 계획 조정을 사용합니다.
5. 오늘·일정 탭의 날짜와 훈련을 확인합니다. 재검토 안내가 남아 있으면 현재 기록에 맞는 조정 여부를 먼저 결정합니다.

예약 백업의 첫 정기 실행 결과는 사용자 환경에서 예정 시간이 지난 뒤 확인할 수 있습니다. `npm run data:schedule -- status`와 개인 maintenance 폴더의 `runs.json`을 사용합니다.
