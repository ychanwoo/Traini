# Workout feedback

`feat/workout-feedback`의 선행 대회 단계 변경은 `f3a1a39`에 커밋했다.
그 이후 피드백·직접 건너뜀 기능은 `docs/workout-feedback.md`의 범위로 구현·검증한다.
사용자가 별도로 요청하기 전에는 커밋하거나 push하지 않는다.

- RPE 1–10, 피로, 통증·불편감, 선택 메모와 서버 보고 시각.
- 일정에서 직접 건너뜀·필수 사유, 완료/미확인으로 정정.
- Garmin 확인·수동 완료·미확인·직접 건너뜀·예정 구분.
- 건너뛴 훈련은 거리·강도 부채가 아니며 자동 보충하지 않음.
- 입력 누락은 정상 회복 증거가 아니며, 통증 보고에는 기존 보호 규칙 우선.
- 저장만으로 OpenAI 호출·계획 자동 재생성을 하지 않음.
- 관리자 권한, RLS, 수정 충돌, 중복 요청, 원본 활동·명시적 결과 보존 검증.
