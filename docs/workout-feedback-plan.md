# 다음 작업: workout feedback

현재 브랜치는 feat/workout-feedback이다. 대회 단계 수정이 선행 변경이며 아직 커밋하지 않는다.
피드백 기능은 별도 작업 단위로 분리하고 아래 범위를 빠뜨리지 않는다.

- 훈련별 체감 강도(RPE 1–10), 피로, 통증·불편감, 선택 메모와 보고 시각 저장.
- 일정 탭에서 직접 **건너뜀** 선택과 사유 입력. 직접 확인한 상태만 미수행/X로 표시.
  날짜가 지났거나 Garmin 활동이 없다는 이유로 자동 실패 처리하지 않는다.
- Garmin 확인·수동 완료·미확인·직접 건너뜀·예정을 구분하고 수정 충돌과 중복 저장 방지.
- 건너뛴 훈련은 다음 주 거리나 남은 요일의 훈련 부채로 더하지 않는다. 보충이 필요하더라도
  현재 부하·회복·대회 일정·훈련 간격 상한을 지키며, 무리한 몰아넣기는 서버 검증에서 거부.
- 실제 수행과 피드백을 주간 리뷰·계획 입력에 연결하되, 미입력을 정상 컨디션으로 해석하지 않는다.
- 통증은 의학적 진단으로 변환하지 않고 기존 보호 규칙을 우선한다.
- 기존 디자인·모바일 프레임과 완료된 훈련·원본 활동을 보존한다.
- 저장만으로 OpenAI를 호출하거나 기존 계획을 재생성하지 않는다.
- 관리자 권한·입력 범위·수정 충돌·건너뜀/완료 변경·부하 상한·모바일·실제 DB 테스트 포함.

사용자가 피드백 작업을 진행하라고 요청할 때 구현한다. 이 문서는 구현 완료를 뜻하지 않는다.
